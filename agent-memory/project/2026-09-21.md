# 2026-09-21

## hy-boot：C 语言微服务框架总体方案 v0.1
- 用户需求：类 Spring Boot 的 C 微服务框架；nginx 接入；XML 外置 SQL（MyBatis 风格）；支持 MySQL/Oracle/达梦（一期只做 MySQL）；模块化拆库，实例链接库即可开发。
- 产出：`docs/architecture-v1.md`（完整方案：选型表、模块分层、HTTP 层、Mapper 设计、DB 抽象与方言、Consul+nginx 集成、里程碑、风险）。
- 关键选型：libevent + llhttp（HTTP）；jansson（JSON）；libxml2（mapper，启动期解析为 AST）；MariaDB Connector/C（LGPL，避开 libmysqlclient 的 GPL）；zlog；inih；Consul（注册中心，抽象成接口保留 Nacos 适配）；CMake + vcpkg。
- 关键设计决策：
  - 进程模型 master/worker（借鉴 nginx），进程内 epoll + 业务线程池，每请求一个内存池。
  - 注册中心用「Consul 主动回调 /health」，服务侧零 SDK，仅 libcurl 调一次 register API。
  - nginx 集成推荐 consul-template 渲染 upstream + reload（起步），后续可选 OpenResty + lua-resty-consul。
  - C 无反射 → 用 tools/gen_meta.py 从 struct 头文件生成字段元数据表，而非手写映射。
  - DB 抽象层含 dialect vtable，解决 MySQL LIMIT / Oracle ROWNUM / 达梦 的分页与占位符差异。
- 待用户拍板：MySQL 客户端协议选择、进程模型（多进程 vs 单进程多线程）、动态标签范围、是否现在就做注册中心接口抽象、是否需 Windows 支持。

### 本次踩坑（可复用经验）
1. **日志队列满大量丢弃**：每条约 1 次 write(2) 系统调用跟不上生产。解法：每分类 64KB 写缓冲合并成批 + 队列满时给消费者 2ms 背压窗口，超时才降级。修完丢弃 0。
2. **keep-alive 第二请求 400**：在 llhttp 回调栈内调 llhttp_reset() 破坏状态机。解法：回调只置 need_reset 标记，llhttp_execute() 返回后再 reset。
3. **llhttp 不是单文件**：release 分支需同时取 src/llhttp.c + src/api.c + src/http.c + include/llhttp.h，只拿 llhttp.c 会缺 llhttp_init/execute 等 API 符号。
4. **libevent 线程支持要另链 event_pthreads**：evthread_use_pthreads 在 libevent_pthreads 里，只链 event 会 undefined symbol。
5. **CMake option() 有缓存**：改了默认值后重新 configure 不生效，必须显式 -DQ_BUILD_HTTP=ON。
